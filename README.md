# スカイライン・テクノロジーズ 企業サイト

スカイライン・テクノロジーズ（Skyline Technologies）の企業サイトです。
クラウド・AI・業務システムで企業の未来を描くソフトウェアカンパニーとして、事業内容や自社プロダクトを紹介しています。

## 概要

サイトは `index.html` 1ファイルで構成された1ページ構成の静的サイトです。ビルドやサーバーは不要で、ブラウザで直接開いて表示できます。

### 掲載内容

- **私たちについて** — 会社のビジョン・紹介
- **事業内容** — クラウドソリューション / AI・データ活用 / 受託開発・DX支援
- **自社プロダクト** — SkyFlow（スカイフロー） / Horizon AI（ホライゾンAI） / Altitude Monitor（アルティチュード・モニター）
- **お客様の声**
- **会社概要**
- **採用案内**
- **お問い合わせ**

## ブラウザで index.html を開く手順

### 方法1：ファイルをダブルクリックする

1. Finder（Windows の場合はエクスプローラー）でこのフォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

### 方法2：ブラウザにドラッグ＆ドロップする

1. Chrome・Safari・Edge・Firefox などのブラウザを起動します。
2. `index.html` をブラウザのウィンドウにドラッグ＆ドロップします。

### 方法3：ターミナルから開く

このフォルダに移動して、次のコマンドを実行します。

```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```
